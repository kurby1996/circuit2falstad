首次使用：安装自动填入助手（Chrome / Edge）
  1. 下载自动填入助手，解压到固定文件夹。
  2. 打开 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions，开启开发者模式，选择「加载已解压的扩展程序」。
  3. 选择解压后的 browser-helper 文件夹。点击扩展图标，授权你要使用的 AI 网站。
  4. 使用 1.1.0 版助手；更新后在扩展管理页点击「重新加载」，再刷新本工具。目标网站需提前登录。识图会自动发送对话并读取本次回复。
