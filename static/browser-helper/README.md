# Circuit2Falstad 网页填入助手

适用于 Chrome / Edge 的 Manifest V3 扩展。配合本地 Circuit2Falstad 使用。

1. 解压 ZIP 到固定文件夹，打开 chrome://extensions 或 edge://extensions。
2. 开启开发者模式，点击“加载已解压的扩展程序”，选择包含 manifest.json 的 browser-helper 文件夹。
3. 点击本扩展工具栏图标，填写工作台所配置的 AI 网页地址，点击“授权这个网站”。只会申请该站点权限；切换到新域名需要重新授权。
4. 刷新本地工作台，选择“免 API 网页识图”，设置目标地址，然后点击“打开 AI 网页并自动填入图片＋提示词”。目标网页需事先登录。
5. 在目标页检查图片附件上传完成，再点击发送。将 AI 的 JSON 回复复制回工作台生成仿真。

不会自动发送对话，不读取 API 配置或密钥。地址与适配选择器保存在工作台当前浏览器的本地存储中。图片和提示词仅在按钮点击后的转移过程中使用，不写入扩展存储。

自动填入通过目标网页的 textarea/contenteditable 与 input[type=file] 完成。页面改版、登录页、跨域重定向、iframe/Shadow DOM、自定义编辑器或拒绝程序上传的网站可能无法自动填入。此时工具会提示，不能视为上传成功。可用自定义 CSS 选择器适配主文档中的控件，也可单独复制提示词、下载图片并手动上传。

本版本已验证本地工作台交互，以及模拟页面中的文字输入、图片控件事件、权限与已有草稿保护。尚未在真实 AI 账号中逐站验证上传完成。
