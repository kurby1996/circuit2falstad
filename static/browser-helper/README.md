# Circuit2Falstad 后台网页识图助手（1.2.0）

适用于 Chrome / Edge 的 Manifest V3 扩展。无需 API Key，复用用户已登录并授权的 AI 网站。

## 首次安装或更新

1. 解压 ZIP 到固定文件夹，打开 chrome://extensions 或 edge://extensions。
2. 首次安装：开启开发者模式，点击“加载已解压的扩展程序”，选择含 manifest.json 的扩展文件夹（项目根目录的 edge-extension，或下载包解压后的 browser-helper）。
3. 更新：用新文件覆盖原扩展文件夹，点击扩展管理页对应扩展的“重新加载”圆形箭头。随后刷新本地工作台。
4. 点击扩展工具栏图标，填写工作台配置的 AI 网页地址并授权。仅申请该网站权限，换域名需重新授权。

## 自动识图

1. 在浏览器中预先登录目标 AI 网站。
2. 在本工具选择“免 API 网页识图”，配置空白新对话地址，上传电路图片。
3. 点击“一键后台识图并自动生成仿真”。助手在后台标签页上传图片、确认附件和发送按钮就绪、发送提示词、等待本次 AI 回复，将完整 JSON 传回工作台自动编译并显示仿真和本地拓扑图。
4. 等待期间保持工作台页面打开。可点击“查看后台网页”检查任务，也可“停止任务”。停止不会撤回已发送的网页消息。

AI 网站处理任务最多等待 3 分钟；页面加载另有 30 秒限时。不会因超时自动重发。浏览器关闭、休眠、网页要求登录/验证码、网络或网站变化会导致失败，需要处理后重新开始。

## 网站适配

已根据实际页面控件属性适配 DeepSeek 的输入框、文件上传、发送按钮与助手回复区域。其他网站提供通用适配，是否可用取决于页面结构；可在工作台配置文字输入框、文件控件、发送按钮、助手回复、附件就绪、生成中状态的 CSS 选择器。只选择 AI 回复区域，避免选择整个聊天页面。iframe/Shadow DOM、自定义编辑器或拒绝程序上传的网站可能需要额外适配。

自动流程要求网页出现新增图片缩略图（或自定义附件就绪元素），同时发送按钮持续可用且页面不处于上传/生成状态。返回结果必须包含当前任务的唯一校验标记、非空元件列表，并在生成结束后稳定 3 秒；旧对话和不完整 JSON 不会被接收。前端自动编译失败会保留收到的 JSON 供检查。

扩展不读取 API 密钥，不绕过登录、验证码或网站限制。图片和提示词只发送至用户选择并授权的网站。任务结果只返回发起任务的本地工作台标签页，不写入扩展持久化存储。

测试命令：`node tests/verify_web_ai.js`、`node tests/verify_web_automation.js`。测试覆盖来源/权限、附件与发送就绪、唯一任务标记、已有草稿、停止、超时、单次发送，以及真实编译器生成电路文本和 SVG。

## 扩展重新加载后的重连

重新加载扩展会使已打开工作台中的旧连接失效。若页面提示通信超时，点击“保留图片并重新连接”，当前电路图片将临时保存在该标签页的会话存储中，刷新后立即恢复并删除临时记录。不会自动重发上一条任务。普通刷新仍默认不加载图片。

## 固定后台标签页

1.2.0 起，所有自动任务复用一个由助手创建的后台 AI 标签页，首次运行才创建。下次任务在原标签页打开所配置的新对话地址，不切到前台；只有点击“查看后台网页”才切换过去。若该标签页被关闭或被导航到其他站点，下次会创建一个替代标签页，不接管或关闭其他网页。

标签页编号只保存在浏览器会话存储中，因此后台服务进程休眠后仍可复用。不会持久化图片、提示词或回复。切换浏览器会话后会重新创建。多个工作台不能同时占用该后台标签页。已存在的旧标签页不自动关闭。
